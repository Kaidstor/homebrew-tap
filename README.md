# Kaidstor's Homebrew tap

```bash
brew install kaidstor/tap/sql-kai
```

| Cask | Description |
| --- | --- |
| [`sql-kai`](Casks/sql-kai.rb) | [Desktop Postgres client](https://github.com/Kaidstor/sql-kai) with SSH tunnels, encrypted vault and a CLI twin for AI agents — signed and notarized |
| [`tcp-kai`](Casks/tcp-kai.rb) | [Desktop client for NestJS TCP microservices](https://github.com/Kaidstor/tcp-kai) with a CLI twin for AI agents — signed and notarized |
| [`sec`](Casks/sec.rb) | [Local secrets manager](https://github.com/Kaidstor/sec) CLI (managed by GoReleaser) |
| [`sec-app`](Casks/sec-app.rb) | [Desktop client for the sec secrets manager](https://github.com/Kaidstor/sec) — search, copy, share links and packs |
| [`finances-kai`](Casks/finances-kai.rb) | [Personal finance CLI](https://github.com/Kaidstor/finances-kai) — payments, receipts, stats and invoice export from the terminal (managed by GoReleaser) |

The GUI apps keep themselves up to date via their built-in updater.
